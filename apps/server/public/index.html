FPV Rig

Sim on the laptop. Phone as a transmitter. Cable link. Nothing leaves this machine.

Sim → run it on the laptop (Chrome / Edge) Transmitter → open on the phone after adb reverse

Phone over USB

  1. Enable Developer options → USB debugging on the phone.
  2. Plug it in, accept the prompt.
  3. Run powershell -ExecutionPolicy Bypass -File tools\tunnel.ps1 on the laptop.
  4. On the phone open http://127.0.0.1:8080/tx/ in Chrome.

No phone? The sim runs on the keyboard: W/S throttle, arrows, Space to arm.
